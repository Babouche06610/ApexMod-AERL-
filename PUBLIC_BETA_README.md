# AERL 1.0.0 — Public Beta

AERL is a local customization and quality-of-life companion for Rocket League.

## Public Beta status

This release is intended for public testing.

Current status:
- Core client: Public Beta
- Garage / supported local swaps: Public Beta
- Alpha Boost / Alpha Wheels: **Work in Progress**
- Goal Explosions: **Experimental — may crash Rocket League**
- Freeplay / replay utilities: Public Beta
- Discord account gate: Public Beta

## Alpha Rewards

Alpha Boost:
- Base item: **Bubbles**
- Install only the Alpha Boost option
- Equip Bubbles inside Rocket League

Alpha Wheels:
- Base item: **Falco**
- Install only the Alpha Wheels option
- Equip Falco inside Rocket League

Alpha Rewards remain Work in Progress because Rocket League updates can change asset behavior.

## Goal Explosions

Goal Explosion swaps are enabled, but AERL displays a warning before applying them.
They are experimental and may cause Rocket League to crash.

## Discord

Official community:
https://discord.gg/aerl

AERL uses Discord OAuth2 to verify membership in the official AERL Discord.
The client never asks users for their Discord password or account token.

## Reporting bugs

Please report:
- AERL version
- Epic Games or Steam
- feature/item used
- expected behavior
- actual behavior
- screenshot/error message when possible
