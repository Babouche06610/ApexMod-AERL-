AERL custom background

At runtime, AERL loads the first matching image from:
%APPDATA%\AERL\Assets\aerl-bg.png
%APPDATA%\AERL\Assets\aerl-bg.jpg
%APPDATA%\AERL\Assets\aerl-bg.jpeg
%APPDATA%\AERL\Assets\aerl-bg.webp

The image is rendered behind a dark translucent layer so UI readability is preserved.
